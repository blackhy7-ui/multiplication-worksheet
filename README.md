# 초등 2학년 두 자릿수 X 한 자릿수 세로셈 곱셈 연습장 🐰✨

초등학교 2학년 학생들을 위한 포근한 동화풍 파스텔 테마의 세로셈 곱셈(두 자릿수 × 한 자릿수) 학습지 웹 앱입니다.

## 🌸 주요 특징
- **세로셈 단계별 풀이 양식**:
  - 1단계: 일의 자리 곱 (예: $19 \times 3 \rightarrow 9 \times 3 = 27$)
  - 2단계: 십의 자리 곱 (예: $10 \times 3 = 30$)
  - 3단계: 최종 곱 합산 ($57$)
- **페이지 구성**: 1페이지당 9문제씩 총 5페이지 (45문제) + 6번째 전체 답지(Answer Key)
- **A4 인쇄 최적화**: 1페이지당 9문제씩 여백에 맞추어 딱 떨어지게 출력 및 PDF 저장 지원
- **인터랙티브 기능**:
  - 🎲 **새 문제 만들기**: 클릭 시 45문제 무작위 자동 생성 (무한 반복 학습)
  - ✨ **채점하기**: 화면에서 직접 풀고 채점하여 별 스티커 획득
  - 👀 **정답 보기/가리기**: 정답 확인 토글
