# 초등 2학년 두 자릿수 X 한 자릿수 세로셈 학습지 웹 앱 기획 및 설계서

## 1. 개요 및 요구사항
- **대상**: 초등학교 2학년 학생 및 학부모/교사
- **학습 내용**: 두 자릿 수 × 한 자릿 수 곱셈 (예: 19 × 3)
- **세로셈 표기 양식**:
  ```text
        1 9
      X   3
      -----
        2 7  (일의 자리 곱 9*3 = 27)
        3 0  (십의 자리 곱 10*3 = 30)
      -----
        5 7  (최종 합)
  ```
- **페이지 구성**:
  - 총 5페이지 (각 페이지당 9문제, 총 45문제)
  - 답지(Answer Key) 페이지 별도 제공 (각 페이지 하단 또는 6페이지 답안 전용 페이지)
  - 인쇄(Print / PDF 저장) 시 A4 규격에 맞춰 1페이지당 정확히 9문제씩 나누어 떨어지도록 `@media print` 스타일 최적화
- **주요 기능**:
  - **문제 자동 생성 (랜덤 난수)**: '새로운 문제 만들기' 클릭 시 45문제 무작위 생성 (초2 수준에 맞춰 10~99 × 2~9)
  - **온라인 풀이 & 자동 채점**: 브라우저에서 입력창에 숫자 입력 후 '채점하기' 누르면 정답/오답 피드백
  - **정답 보기/숨기기 토글**: 교사용/부모용 및 자가 점검용
  - **A4 학습지 인쇄 기능**: 브라우저 인쇄 버튼을 누르면 컨트롤 바가 숨겨지고 깔끔하게 5페이지 문제 + 답지가 A4로 출력

## 2. 디자인 및 테마 가이드
- **톤**: 부드러움, 순수, 아기, 포근함, 동화
- **색상**:
  - 배경: `#FFF5F5` (베이비 핑크 화이트)
  - 텍스트: `#7B6B8D` (소프트 라벤더 그레이)
  - 강조: `#FFB5C2` (베이비 핑크), `#B5D8F7` (베이비 블루), `#FFEAA7` (소프트 옐로우)
- **아이콘 & 그래픽**:
  - 몽실몽실 구름, 별, 달, 토끼, 곰 인형, 풍선 테마 데코레이션
  - 둥근 모서리와 포근한 그림자
- **타이포그래피**:
  - 둥글고 귀여운 고딕/손글씨 느낌의 웹폰트, 큰 글씨, 넉넉한 여백

## 3. 세로셈 격자(Grid) 구조 상세
한 문제당:
- 첫 줄: 두 자릿수 (십의 자리, 일의 자리)
- 둘째 줄: `X` 연산 기호 + 한 자릿수 (일의 자리)
- 굵은 구분선 (`border-bottom`)
- 셋째 줄: 일의 자리 곱셈 결과 (십의 자리, 일의 자리 네모칸)
- 넷째 줄: 십의 자리 곱셈 결과 (십의 자리 또는 백의 자리 포함 네모칸)
- 굵은 구분선 (`border-bottom`)
- 다섯째 줄: 최종 합산 결과 (백, 십, 일의 자리 네모칸)

## 4. 파일 구조
- `index.html`: 단일 페이지 웹 애플리케이션 (HTML5)
- `style.css`: 동화풍 파스텔 스타일링 및 A4 프린트 전용 CSS 규칙
- `script.js`: 문제 생성 로직, 세로셈 단계별 자동 계산, 인터랙티브 채점 및 인쇄 핸들러
